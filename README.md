# Thangam Hospitals V2

Patient-first Next.js website for Thangam Hospitals, Kandigai, Chennai.

## Run locally

```bash
npm install
npm run dev
```

## Content safety

All unknown phone numbers, street addresses, doctor data, facilities and testimonials are clearly marked as placeholders. Update `data/site.ts` after facts are verified. Replace the canonical domain in `app/layout.tsx`, `app/sitemap.ts` and `app/robots.ts` if the production domain differs.
